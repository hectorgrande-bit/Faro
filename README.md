# Faro

**Faro** es el design system de **SavePoint**, una app social de reseñas de videojuegos.

Faro reúne los fundamentos visuales, los componentes y las pautas de uso que dan forma a la interfaz de SavePoint, para que todo el producto se vea, se sienta y se comporte de forma coherente.

---

## ¿Qué es SavePoint?

SavePoint es una app para llevar el registro de tu vida como jugador y compartirla con otras personas. Cada usuario tiene su cuenta y desde ella puede:

- **Registrar** los juegos a los que ha jugado.
- **Puntuar** cada juego y **escribir reseñas**.
- **Crear listas**: juegos pendientes, juegos que quiere comprar o cualquier colección propia.
- **Subir fotos** de sus juegos.
- **Seguir** a otros usuarios y que otros le sigan.
- **Comentar** las reseñas de sus amigos.

Todo ello pensado para compartirse: tu actividad, tus listas y tus opiniones forman parte de una comunidad.

## ¿Qué es Faro?

Faro es la base común sobre la que se construye la interfaz de SavePoint. Su objetivo es que diseñar y desarrollar nuevas pantallas sea más rápido, más consistente y más accesible.

Incluye (o incluirá):

- **Fundamentos**: color, tipografía, espaciado, iconografía, elevación, radios y movimiento, definidos como *design tokens*.
- **Componentes**: piezas de interfaz reutilizables (botones, campos de formulario, tarjetas de juego, valoraciones, avatares, listas, comentarios…).
- **Patrones**: soluciones a problemas recurrentes del producto, como el feed de actividad, la ficha de un juego, el perfil de usuario o el flujo para escribir una reseña.
- **Pautas**: criterios de uso, accesibilidad y tono de voz.

## ¿Para quién es?

- **Diseño de producto**: para crear pantallas de SavePoint a partir de piezas ya definidas, sin reinventarlas.
- **Desarrollo**: para implementar la interfaz con componentes y tokens listos para usar.
- **Producto y contenido**: como referencia compartida de cómo se ve y cómo habla SavePoint.

Y, en último término, para las personas que usan SavePoint, que disfrutan de una experiencia coherente, clara y accesible.

## Qué vamos a construir

1. **Tokens de diseño** — la paleta, la escala tipográfica, el espaciado y el resto de fundamentos en un formato único que se pueda usar tanto en diseño como en código.
2. **Librería de componentes** — empezando por los básicos (botón, input, avatar, etiqueta, icono) y siguiendo con los propios de SavePoint (tarjeta de juego, puntuación, reseña, lista, comentario, foto).
3. **Patrones de producto** — composiciones para las pantallas clave: feed, perfil, ficha de juego, listas y reseñas.
4. **Documentación** — guía de uso de cada pieza, con ejemplos, buenas prácticas y criterios de accesibilidad.
